# News App

A Flutter news application developed during my Mobile Application Development training.

## Features

- Browse news articles by category
- Fetch news from a REST API
- Display article images with caching
- View full articles within the application
- Save user preferences locally
- Responsive and user-friendly interface

## Technologies & Packages

- Flutter & Dart
- Dio
- Provider
- Cached Network Image
- WebView Flutter
- Shared Preferences
- Lottie
- Google Fonts

## Project Structure

The project follows a feature-based structure to organize the application code and keep the different parts of the app maintainable.

## Getting Started

### Prerequisites

- Flutter SDK
- Android Studio or another Flutter-compatible IDE

### Installation

1. Clone the repository.
2. Navigate to the project directory.
3. Run:

```bash
flutter pub get
```
4. Run the application using an Android Emulator or a connected Android device.
